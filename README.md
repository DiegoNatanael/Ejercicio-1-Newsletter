## 📌 Descripción
Desarrolla una página web usando HTML y CSS que permita a los usuarios suscribirse a un Newsletter. Este reto te ayudará a practicar tus conocimientos básicos de diseño web, incluyendo el uso de campos de entrada (input) y botones.

---

## 🚀 Tecnologías utilizadas

- CSS3
- Google Fonts (Outfit)

## 📝 Reflexión
Durante el desarrollo de este proyecto, se practicó la estructuración semántica con HTML y el uso de variables CSS para un diseño consistente. Se implementaron sombras personalizadas y transiciones suaves para mejorar la experiencia del usuario (UX). El principal aprendizaje fue la importancia del espaciado (padding/margin) y la jerarquía tipográfica para lograr un mejor aspecto.
